ニッチSNS（コミュニティ）参入の検討
前提の事実確認と案カタログ v1

作成日：2026-09-02 ／ 状態：案（未承認・ゲート0未実施） ／ 合同会社R.Y.S
この資料は正本ではありません。案を1つ選んだあと、その案について decision-gate スキルの「ゲート0（6つの問い）」を通します。

0. 結論（先に3行）

  1. 「SNSは乗り換えないから参入好機」という見立ては、半分は正しく、半分は逆です。乗り換えないのは既存SNSの強みであって、新規SNSにとっては「来てもらえない」という逆風そのものです。
  2. ニッチSNSは「作れるか」ではなく「最初の1,000人が集まるか」「集まった後に金になるか」で決まります。作る難易度はAIでほぼゼロになりました（ぬい日和は個人が約1か月・Claude Codeで開発）。だからこそ、開発力は差別化になりません。
  3. SNS単体で月50万円は、現実的な確率が低い。収益はSNSの外（モノ・道具課金・場）に置く設計にしないと成立しません。国内最大級の趣味SNSであるYAMAPですら、DL数460万・売上約19.7億円で純損失4.19億円です。

1. ご認識の検証（事実とリスクを分けて）

1-1「デジタル商品はAIで誰でも作れるので、最終的に淘汰される」

部分的に正しい正確に言い直すと、淘汰されるのは「作れること」を売りにした商品です。制作コストが下がるので、コンテンツ・システムそれ自体の希少性は消えます。この部分のご認識は妥当です。

ただし「デジタル商品＝全部ダメ」ではありません。AIで複製できないものが2つ残ります。

  • 集まっている人（ユーザーの蓄積） … 同じアプリを作れても、そこにいる4万人は作れません。
  • 溜まっているデータ … 過去の記録・写真・履歴。乗り換えると消えるので、これが唯一の乗り換え障壁になります。

SNSに目を付けられたのは、この2つを狙っているという意味で筋は通っています。

1-2「SNSから別のSNSに乗り換える人は少ないから、SNSはやる価値がある」

ここが一番危険な前提です。この命題は、あなたが後発である以上、不利な側にしか働きません。

「乗り換えない」＝「X・Instagramを使っている人は、あなたのSNSに移ってこない」ということです。あなたが将来手にする守りは、いま参入するときの壁とまったく同じ形をしています。

実際、ぬい日和が伸びた経路は「X・Instagramでの拡散」でした（後述）。つまり新規SNSは、既存SNSを集客チャネルとして借りて立ち上がります。既存SNSの外に出る話ではありません。

ただし「だからやめるべき」ではありません。正しい読み替えは次のとおりです。

  • ✕「乗り換えないから、SNSは参入する価値がある」
  • ○「乗り換えないから、いま既存SNSで満たされていない人を、既存SNS経由で連れてくるしかない」

2. 事実：ぬい日和（ご覧になったアプリ）

まずアプリ名の確認です。「ぬいびおり」は「ぬい日和（ぬいびより）」と思われます。よく似た先行アプリに「ふわもこSNS」「ぬいとも」もあり、この領域はすでに複数存在します。

項目事実
公開日2026年6月17日（iOS）
開発期間約1か月
開発体制個人開発1名（Shin氏）
開発手段Anthropic の Claude Code を使用。イメージ図は GPT Image 2.0
需要検証着想当日にAIで完成イメージ図を作り、X・Instagramで事前登録を募集。1日で30〜40件集まったため開発着手

この事例から読み取るべき、都合の悪い事実

  1. 4万人いても、収益は月額300円の任意課金のみです。仮に課金率を（一般的な無料アプリの水準として高めの）5%と置いても 2,000人×300円＝月60万円、Apple手数料15〜30%を引いて月42〜51万円。推計課金率1%なら月8〜12万円です。実際の課金率は公表されておらず【未確認】ですが、「応援プラン」という名前自体が、機能で課金させる設計になっていないことを示しています。
  2. 約1か月で作れています。つまり開発力はもう参入障壁ではありません。あなたが同じものを作れるのと同様に、他の誰かもすぐ作れます（実際、ふわもこSNS・ぬいともが先行していました）。
  3. 勝敗を分けたのは開発ではなく「着想当日の事前登録テスト」です。絵を1枚作ってSNSで募集し、1日で30〜40件。ここが本体です。

3. 事実：ニッチSNSは「規模が出ても」黒字化しない

国内の趣味特化型SNSで最も成功している部類のYAMAP（登山）の実数です。

期売上高純損益アプリDL数
第10期15億6,100万円（前期比＋28%）△4億4,393万円400万（2023年10月）
第11期19億7,400万円（前期比＋26.3%）△4億1,890万円460万（2024年9月）

YAMAP社自身は、この時期を将来の成長に向けた「かがむ」局面（意図的な先行投資）と説明しています。売上の伸びはプレミアム会員（課金）とYAMAP STORE（EC＝物販）によるものとされています。

読み取り：460万DLという、個人・小規模事業者がまず届かない規模に達しても、SNS機能そのものは黒字を生んでいません。稼いでいるのは「物販」と「有料の道具（地図機能）」です。

あなたの目標は「月50万円が5年10年続くこと」であり、資金調達して赤字を掘る事業ではありません。したがって、SNSを収益源にする設計は最初から採ってはいけません。SNSは集客装置として置き、収益は別の場所に置く必要があります。

4. ニッチSNSが死ぬ理由は、2つしかない

#死因中身潰し方
死因1コールドスタート誰もいないSNSには誰も投稿しない。投稿がないから人が来ない。最初の1,000人が集まらず終わる。国内のニッチSNSの大半がここで消える「1人で使っても価値がある道具」から始める（後述）
死因2金にならないニッチはエンゲージメントは高いが母数が小さい。広告は成立せず（PV単価×母数が足りない）、課金は「応援」止まりになる収益をSNSの外に置く（モノ・道具課金・場）

逆に言えば、この2つに答えを持っている案だけが、検討に値します。面白いかどうかではありません。

5. 設計原則（案を作るときの型）

原則1：まず「一人で使える道具」を作り、SNSは後から生やす

ヤマレコもYAMAPも、出発点は「登山の記録を残すツール」でした。1人で使っても完結するので、ユーザーが0人でも成立します。人が溜まった後に、記録が自然と共有され、SNSになりました。

一方、最初から「投稿して交流するSNS」として作ると、ユーザー0人の日は価値も0です。これがコールドスタートの正体です。

判定に使う一文：「このアプリを、ユーザーが自分ひとりしかいない状態で1か月使い続ける理由があるか？」
書けないなら、その案は死因1で死にます。

原則2：収益の置き場所を、案を出す時点で決めておく

置き場所中身あなたとの相性
① モノ（EC・二次流通）その趣味の消耗品・パーツ・中古品を自社で売る最良。物販・仕入れ・在庫の実務がすでにある。寝かせ転売の知見も効く
② 道具課金（サブスク）記録・管理の便利機能を有料化（YAMAPの地図型）良。マイクロSaaSの検討経験が活きる
③ 場（オフライン）即売会・走行会・撮影会の参加費、出展枠可。ただし現場稼働が発生する
④ 送客手数料職人・業者に依頼を流して手数料可。ただし決済とトラブル対応の責任が乗る
⑤ 広告純広告・アフィリエイト不可。ニッチでは母数が足りない。これしか書けない案は落とす

原則3：自分が当事者である領域を優先する

ぬい日和の決定打は「妻が当事者だった」ことです。最初の30人を集められるかは、その界隈に自分が居るかどうかでほぼ決まります。
ご趣味・ご関心（水上バイク／車／機械式時計／香り）は、その意味で他の案より初速で有利です。

7. 選ぶときの見方（Claudeからの推奨）

  • 型Aは、あなたの本業（仕入れ・在庫・発送・二次流通）がそのまま収益源になります。SNSは「その商品を欲しい人が集まっている場所」を自分で持つという意味になり、集客コストが下がります。寝かせ転売との相性も良い（A-17 絶版部品、A-19 標本、A-06 廃番香水など、いずれも「寝かせて上がる」性質を持ちます）。
  • 型Eは母数が小さくても客単価が高いため、月50万円という目標に対して必要ユーザー数が最も少なくて済みます。
  • 型B単独は非推奨：道具課金だけで月50万円（例：月500円×1,000人）を個人向けで集めるのは、集客の観点で最も難しい部類です。型Aの補助機能として置くのが現実的です。

ただし、これはClaudeの推奨であって決定ではありません。ご方針どおり、面白いと感じた案を自由に選んでいただき、選ばれた案についてだけ検証を進めます。
