止める条件7つのうち、3つが明確に該当し、1つが該当の可能性が高い状態です。

③ ★顧客はそもそも2つを並べて比べてくれるか

POSを使う層は、比べてくれません。条件6bに該当します。

POSを使わない零細層は探しますが、その層が最初に見つけるのは無料の片岡オート製です。ここでは比較の土俵には上がれますが、相手が無料です。

保存年数古物営業法 第18条第1項。最終の記載をした日から3年間
★電子での記録法律上、正面から認められています。第16条本文が「帳簿…に記載をし、又は電磁的方法により記録をしておかなければならない」と、紙と電子を並列で規定。POSシステムによる記録も、法定の記載事項を網羅していれば該当する（警察庁の解釈運用基準）
★クラウド保存警察庁が明示的に認めています。解釈運用基準（令和6年8月14日・警察庁丙生企発第272号）に「各営業所等において当該記録をプリントアウトすることが可能である限り、データ自体は本社や本部のコンピュータにおいて一括管理することも許容される」と明記。
ただし条件があり、各営業所に印刷に必要な機器を備え付け、直ちに書面に表示できる状態を常に確保する必要があります（第18条第1項）
まとめ記帳の禁止「その都度」とは受け取り・引き渡しのたびごとの意味で、1週間分・1か月分をまとめて記載することは許されない（同解釈運用基準）

10. ★カタログ全体への影響（重要）

同じ穴が、カタログの他の案にも空いている可能性があります。

C-03はカタログで「大」4つの最上位、参入しにくさも「空いている可能性」でした。その評価が誤っていたのです。

なぜ誤ったのか。カタログの C-03 の欄には、既存の競合としてRECORE・スマレジ買取オプション・NRAクラウド・NV CLOUD が既に書かれていました。書かれていたのに、判定は「確立した専用SaaSの固有名詞は薄い」＝空いている、でした。

何を見ていたか何を見ていなかったか
「古物台帳専用のSaaSがあるか」
→ 薄い → 空いている、と判定した		「もっと大きいシステムが、この機能を中に持っていないか」
→ 持っていた。しかも無料同梱で

カタログの評価軸には「上位カテゴリに内包されていないか」という観点がそもそも入っていませんでした。4項目（作れる／需要／リーチ／営業）にも、除外条件E1〜E4にも、この観点はありません。E2が近いですが、E2は「大手の標準機能に含まれ、かつ自社では同等の実装ができないと確定する場合」という厳しい条件で、実装できてしまう機能は素通りします。

したがって、残る77件の中に、同じ理由で過大評価されている案が他にもあると考えるべきです。特に危ないのは、業種特化のPOS・基幹システムが存在する領域の案です。11節に対処案を書きました。
